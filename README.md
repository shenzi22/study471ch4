# Packet — Chapter 4 study room

A responsive study app based on the five supplied CSPC 471 slide decks. Includes topic notes, 39 explained practice questions (9 adapted from the Chapter 5 recap), flashcards, topic filters, search, and missed-question review. Progress is stored in browser localStorage.

## Run

Requires Node.js 18 or newer; no dependency installation needed.

```sh
npm start
```

The server listens on port 3000 (override with `PORT`). Alternatively, serve this directory with any static web server. Google Fonts are optional; system font fallbacks work offline.

Questions are adapted study aids, not a prediction of quiz content. Slide references accompany explanations. The IPv6 address-count typo in the slides is explicitly corrected in the notes.
